# Справочник локаций (City) и импорт из ГАР/ФИАС

В проекте справочник хранится в таблице **`City`** (название историческое): это **список локаций РФ**, импортируемый из официальных XML-выгрузок ГАР/ФИАС.

## Какие уровни ГАР импортируем

Импортируем только адресные объекты уровней:
- **2, 3, 4, 6** — административные/муниципальные единицы, поселения и населённые пункты;
- **5** — города (`typeName="г"`);
- **1** — только города федерального значения (в ГАР это тоже `typeName="г"`, но на уровне субъекта).

Улицы/дома/помещения и другие “нижние” уровни **не импортируются**.

## Где лежит код

- Скрипт импорта: `backend/scripts/import-gar-cities.ts`
- API подсказок: `backend/src/cities/cities.service.ts` → `GET /cities/suggest`
- Фронт: `frontend/shared/ui/CityAutocomplete.tsx` → `/api/cities/suggest` → backend

## Команды импорта

Запускать из папки `backend`.

### Первичная заливка (полная)

Скачает `gar_xml.zip` и сделает `upsert` в таблицу `City`.

```bash
npm run cities:update -- --mode full
```

Можно указать, куда сохранять большой архив:

```bash
npm run cities:update -- --mode full --out "/path/to/store/gar"
```

### Обновление (дельта)

Скачает `gar_delta_xml.zip` и сделает `upsert` изменений:

```bash
npm run cities:update -- --mode delta
```

### Если архив уже скачан (без download)

```bash
npm run cities:update -- --zip "/path/to/gar_xml.zip"
```

### Если XML уже распакованы в директорию

```bash
npm run cities:update -- --dir "/path/to/unzipped/gar"
```

## Важные замечания

- **Backfill при изменении импортируемых уровней**: если вы расширили набор уровней, **дельта не заполнит** исторически “пропущенные” объекты. Нужен прогон `--mode full` (или `--zip` на полный архив).
- **Матчинг по региону**: для локаций важны `regionCode/regionName` — они берутся из `AS_ADM_HIERARCHY` (или из префикса папки в ZIP, если он есть).

## Troubleshooting

### `Import failed: ... invalid block type` / `bad zipfile offset`

Это почти всегда означает **повреждённый ZIP** (часто из-за некорректного resume/обрыва загрузки).

Что делать:
- удалите/переименуйте битый `gar_xml.zip`;
- перезапустите `npm run cities:update -- --mode full` (или скачайте заново и используйте `--zip`).

Скрипт старается детектить такие случаи заранее и откладывать подозрительные файлы в `*.mismatch.*` / `*.corrupt.*`.
