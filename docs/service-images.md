# Фотографии услуги

У услуги может быть до 10 фотографий JPEG, PNG или WebP, каждая до 10 МиБ. `Service.images` хранит упорядоченные URL, а `Service.image` остаётся обложкой для существующих карточек и заявок. Первое изображение становится обложкой; при его удалении выбирается следующее.

Миграция `20261106160000_service_images` добавляет массив, переносит существующую обложку в его первый элемент и ограничивает размер массива на уровне БД. Она применена локально; перед развёртыванием backend требуется применить её на сервере.

`POST /pro/services/:id/image` добавляет один файл, повтор того же содержимого не создаёт дубликат. Блокировка строки услуги защищает лимит при одновременных загрузках. `DELETE /pro/services/:id/image?imageUrl=...` удаляет выбранное изображение; без параметра удаляется обложка. Проверка принадлежности услуги исполнителю сохранена. Эти маршруты проксируются через `/api/pro/services/...`.

Редактор позволяет выбрать несколько файлов. Успешно загруженные изображения сохраняются при сбое следующего файла; оставшиеся можно загрузить повторно. При сбое после создания услуги повтор использует уже созданную услугу. Страница услуги показывает галерею со стрелками и счётчиком.

Фотографии публичной карточки используют существующие `S3_PUBLIC_BUCKET`, `S3_ENDPOINT`, `S3_KEY`, `S3_SECRET`, `CDN_PUBLIC_BASE_URL`, `S3_PUBLIC_PREFIX`. Настройки приватного хранилища документов не используются для публичной галереи.

Проверено 2026-11-06: интеграционные тесты с локальной PostgreSQL и имитацией S3 (10 из 11 параллельных загрузок, повтор, удаление, обложка, изоляция исполнителей), компонентные тесты выбора/повтора и создания услуги без дубликата. В браузере на синтетических изображениях проверены мобильный и настольный редактор, удаление с перезагрузкой, смена обложки и перелистывание публичной галереи. Тестовые записи удалены. Сборка backend проходит; глобальная проверка типов frontend содержит существующие ошибки вне реализации галереи.

Проверка настроенного локально публичного бакета вернула HTTP 404 на HeadBucket. Реальная загрузка в публичное облачное хранилище не подтверждена: требуется действующий публичный бакет и соответствующие реквизиты окружения. Приватный бакет паспортов этой проверкой не затронут.
