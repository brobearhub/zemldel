# Журнал оффлайн-оплат по заявке — Design

Дата: 2026-08-13  
Статус: approved

## Цель

Учитывать по заявке полную цену сделки и поступления денег **вне платформы**: аванс, оплата кадастра и т.п. Показать обеим сторонам «внесено / осталось». Запретить «Завершить», пока остаток > 0.

Это **не** онлайн-эквайринг и не возврат старой сущности `Payment` (эскроу). Платформа деньги не проводит.

## Решения

| Вопрос | Решение |
|--------|---------|
| Где сумма сделки | `Request.totalAmountKopecks` (nullable) |
| График/строки оплат | `RequestPayment` (сумма + комментарий) |
| Подтверждение оплаты | `RequestPayment.paidAt` (nullable): `null` — план, дата — подтверждён |
| Остаток | Производный: `total - sum(confirmed CONTRACT payments)` |
| Кто создаёт график | Только исполнитель выбранной сделки после `lockedAt` |
| Кто подтверждает «Оплачено» | Заказчик и исполнитель |
| Кто читает | Заказчик и этот исполнитель |
| «Завершить» | Жёсткий запрет, если цена задана и `remaining > 0` |
| Цена не задана | «Завершить» как сейчас (старые заявки) |
| Статусы оплаты | Не вводим (`PAID` и т.п.) |

## Модель

- `Request.totalAmountKopecks Int?` — полная цена в копейках.
- `RequestPayment`: `requestId`, `providerId`, `amountKopecks` (> 0), `comment`, `paidAt?`, `createdByUserId`.
- Писать можно, пока статус не `COMPLETED` / `CANCELLED` / `CLOSED`.
- Уменьшать `total` ниже уже внесённого можно (остаток ≤ 0 → complete разрешён). Переплата (`remaining < 0`) complete не блокирует.

## Флоу

После lock исполнитель задаёт цену и создаёт график платежей (строки с `paidAt = null`). В `ACCEPTED` заказчик видит «осталось доплатить N» (перевод вне сайта) и подтверждает оплату по строкам кнопкой «Оплачено» (может и исполнитель). Подтверждённые строки уменьшают остаток → остаток 0 → «Завершить» → `COMPLETED`.

## UI

Панель «Оплата» в карточке заявки: в футере карточки — триггер «Оплата», по клику открывается оверлей внутри карточки (рядом с «Клиент/Исполнитель»). Внутри панели: итоги + список строк. У исполнителя — форма цены и добавления строк графика. У заказчика — только подтверждение «Оплачено».
