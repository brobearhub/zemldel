# Прогресс: скрывать пустую область файлов (customer) — Design

Дата: 2026-08-11  
Статус: approved

## Цель

В блоке «Прогресс» на стороне клиента:

- не показывать область вложений, если нет ни файлов, ни запросов;
- не показывать пустую секцию по отдельности («Файлы исполнителя» / «Нет файлов», «Документы от клиента» / «Запросов нет»);
- не показывать плейсхолдер «Без описания», если описания нет;
- если этап пустой (нет описания, файлов и запросов) — не раскрывать и скрыть иконку стрелки.

## Контекст

`StageCard` в `frontend/widgets/request-work-progress/ui/RequestWorkProgress.tsx` всегда рендерит обе секции с плейсхолдерами «Нет файлов» / «Запросов нет». На customer это визуальный шум, когда этап без вложений.

## Решения

| Вопрос | Решение |
|--------|---------|
| Сторона | Только `mode === "customer"` |
| Provider | Без изменений (секции и кнопки всегда) |
| Условие показа области | `files.length > 0 \|\| docSlots.length > 0` |
| Пустое состояние | Не рендерить область целиком |
| Частично пусто | Показывать только непустые секции |
| «Файлы исполнителя» | Только если `files.length > 0` |
| «Документы от клиента» | Только если `docSlots.length > 0` |
| Описание | Показывать только если `description.trim()` непустой; «Без описания» не рендерить |
| Раскрытие (customer) | Стрелка и toggle только при `hasStageExpandableContent`; иначе строка статичная |
| Provider | Всегда можно раскрыть (статус / кнопки файлов) |
| Подход | Helpers + условный рендер секций |

## Компоненты

### `hasStageAttachments` (новый)

Путь: `frontend/widgets/request-work-progress/lib/has-stage-attachments.ts`

```ts
hasStageAttachments(stage: { files: readonly unknown[]; docSlots: readonly unknown[] }): boolean
```

Возвращает `true`, если есть файлы или doc-slots.

Тест: `has-stage-attachments.test.ts` — пусто / только files / только docSlots / оба.

### `StageCard`

Для customer:

- область вложений — только при `hasStageAttachments(stage)`;
- секция «Файлы исполнителя» — только при `files.length > 0`;
- секция «Документы от клиента» — только при `docSlots.length > 0`.

Provider-ветка не меняется (плейсхолдеры и кнопки остаются).

## Вне scope

- Backend / DTO / API
- Provider UI
- Редизайн карточек этапов

## Критерии готовности

- [x] Customer + пустые files и docSlots → область файлов не видна
- [x] Customer + только docSlots → видна только «Документы от клиента»
- [x] Customer + только files → видна только «Файлы исполнителя»
- [x] Provider без регрессий
- [x] Unit-тесты на helper зелёные
