# Карточка заявки в профиле — перераспределение пространства — Design

Дата: 2026-08-11  
Статус: approved

## Цель

В списке заявок на `/profile` убрать пустое пространство справа в карточке: сделать текст заявки главным сигналом, статус и дату разнести по горизонтали на desktop, упростить мобильную колонку.

## Контекст

Карточка рендерится в `frontend/widgets/customer-requests/ui/CustomerRequestsSection.tsx`. Сейчас вертикальный стек слева: тип заявки + статус, исполнитель, локация, текст, дата — справа остаётся ~60–70% пустоты.

## Решения

| Вопрос | Решение |
|--------|---------|
| Подход | Двухрядная сетка на desktop; вертикальный стек на mobile |
| Заголовок типа сверху | Убрать («Свободная заявка» / «Заявка по категории» / название услуги) |
| Главный текст | `message`, 1 строка + ellipsis |
| Пустой message | Fallback `"Без описания"` |
| Услуга / категория | Мелкая secondary-строка под текстом: `SERVICE` → `serviceTitle`; `CATEGORY` → `"Заявка по категории"`; `FREEFORM` → не показывать |
| Статус desktop | Верхний правый угол, в одной строке с текстом |
| Статус mobile | Отдельной строкой **над** текстом |
| Desktop meta | Слева `Исполнитель · Локация` (одна строка, truncate), справа дата |
| Mobile meta | Три отдельные строки: исполнитель → локация → дата (только непустые) |
| Статусы / цвета | Без изменений (`Chip` + `getRequestStatusLabel`) |
| Клик / CLOSED | Без изменений |

## Раскладка

### Desktop (`md+`)

```
[ Текст заявки…                    ] [Статус]
[ Услуга / категория (если есть)              ]
[ Исполнитель · Локация            ] [Дата]
```

### Mobile (`xs`)

```
[Статус]
[ Текст заявки… ]
[ Услуга / категория (если есть) ]
[ Исполнитель ]
[ Локация ]
[ Дата ]
```

## Правила строк

- Текст заявки и subject-subtitle: `noWrap` + `textOverflow: ellipsis`.
- Desktop meta-слева: одна строка, truncate; дата справа не сжимается (`flexShrink: 0`).
- Исполнитель: префикс `Исполнитель: {providerName}`; строка отсутствует, если `providerName` пуст.
- Локация: на desktop через ` · ` после исполнителя (или одна локация, если исполнителя нет); на mobile — отдельная строка `Локация: {location}` только при наличии.
- Дата: `formatDate(createdAt)` как сейчас.

## Скоуп

**В scope**
- Только разметка карточки в `CustomerRequestsSection.tsx`.

**Out of scope**
- Страница детали заявки
- Pro-лента / `entities/request` `RequestCard`
- API, фильтры, статусы, клик-логика
- Новые зависимости / вынос в отдельный shared-компонент

## Реализация

Responsive MUI `Stack`/`Box` по breakpoints `xs` / `md+`. Без изменения публичных контрактов.
