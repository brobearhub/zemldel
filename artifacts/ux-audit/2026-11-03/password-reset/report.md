## Повтор после перехода на Postbox и передеплоя

03.11.2026, 13:12–13:14 (Asia/Yekaterinburg). Пользователь сообщил о передеплое. Выполнена одна дополнительная отправка через ту же форму для photoburg@yandex.ru, Chrome request 132. Результат: HTTP 500, видимая ошибка отправки. Всего с начала проверки — три запроса.

В настройках backend ONREZA прочитаны несекретные значения: SMTP_HOST=postbox.cloud.yandex.net, SMTP_PORT=465, SMTP_FROM=reset-password@zemledel.pro. Секрет не раскрывался. В логах новый backend deployment 01a1a073 запущен в 13:11:07.

- 13:12:37: frontend `timeout of 15000ms exceeded`.
- 13:14:22: новый backend `PasswordResetService`, `Error: Connection timeout`, стек Nodemailer SMTPConnection с DNS resolver callbacks.

Таким образом, сбой подключения воспроизведён после смены SMTP-провайдера. Логи не позволяют отделить проблему DNS от сетевого доступа к SMTP. Неверный API-ключ не подтверждён: ошибка аутентификации отсутствует. Следующая диагностика нужна из runtime ONREZA: разрешение имени postbox.cloud.yandex.net и исходящее TCP/TLS-соединение на порт 465. Настройки сервера и исходный код агентом не изменялись.
