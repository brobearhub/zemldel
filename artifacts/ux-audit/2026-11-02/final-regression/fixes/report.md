# Исправление замечаний финальной регрессии

Дата: 02.11.2026. Основание: [браузерная регрессия](../report.md). Три подтверждённых P2 исправлены; прежнее наблюдение о черновике уточнено отдельным контролируемым экспериментом.

## Изменения

1. **Архивный чат сохраняет выбор.** `resolveActiveConversationId` различает обычное обновление и изменение контекста выбора исполнителя. Карточка клиента сохраняет вручную открытый доступный чат при polling/focus; при фактической смене `providerId`/lock переключается к новому исполнителю. Действие «Перейти к выбранному исполнителю» по-прежнему переключает явно. Если текущий тред исчез, выбирается доступный чат назначенного исполнителя.
2. **Права чата актуализируются без отказа при отправке.** Новый `ProRequestWorkspace` передаёт в открытый чат обновлённые данные из `ProRequestDetails`. Архивный контекст сразу запрещает ввод, отправку, повторную отправку и ответ на сообщение. Клиент также передаёт архивный контекст выбранного треда. Сам чат дополнительно перечитывает access по таймеру видимой страницы, при focus и восстановлении socket-соединения. Устаревшие отменённые ответы не применяются. Ошибка проверки прав закрывает запись; серверные проверки сохранены.
3. **Мобильные отклики не перекрываются действиями.** Убрано абсолютное размещение `secondaryAction`. На мобильных ширинах действие/статус находится отдельной строкой под именем и фрагментом переписки. На более широком экране действие размещено рядом, в отдельной области. Имя допускает переносы; текущая компания и метка исполнителя остаются видимыми.

Backend и бизнес-правила в этой задаче не менялись. Предыдущие незакоммиченные изменения необязательной подписи и скачивания сохранены.

## Повторная проверка в Chrome

Использованы те же три сессии Chrome DevTools MCP. Для проверки динамического переключения подготовлена новая FREEFORM `038a9fa8-6fa4-4370-a68d-032682f27e06`. Создание и два отклика подготовлены через авторизованный браузерный API; выбор, отмена и повторный выбор выполнены интерфейсом.

| Проверка | Результат |
|---|---|
| До выбора у ООО открыт чат | Ввод доступен, «Ответить» доступно |
| Клиент выбирает ИП | У ООО без reload отключены ввод и ответы, появился текст архива |
| Контроль сетевых отказов | После выбора нет запросов с `403`; пробная отправка для актуализации прав не требовалась |
| Клиент вручную открывает архив ООО | Чат и сообщение доступны для чтения, ввод заблокирован |
| Архив после 12 секунд и focus | Выбранным остаётся ООО, архив не переключается обратно на ИП |
| Отмена выбора ИП до договора | У ООО восстановились ввод и ответы, архивная пометка исчезла |
| Выбор ООО вместо ИП | Клиент переключился на ООО; у ООО ввод доступен, у ИП отключены ввод и ответы, показан архив |
| 320 px до выбора | Полные имена видны; кнопки находятся снизу, горизонтального переполнения нет |
| 360 px после выбора | Имя, метка исполнителя и статус не перекрываются; DOM-проверка прямоугольников текста/действия не обнаружила пересечения |
| 390 px, архив | Строки не перекрываются, архивная переписка читается |

Новых вкладок не создавалось. Реальных работ, платежей и публикации новых отзывов в этом проходе не было. Новая запись оставлена с выбранным ООО для визуального осмотра; ИП видит архив.

## Уточнение о черновике отзыва

На существующей завершённой заявке `922e78dd-d936-44e8-bcfe-787881aab206` выбраны 4 звезды и введён тестовый комментарий без публикации.

- При изменении только ширины **390 → 1440 → 390** значение оценки и текст сохранились. JavaScript-маркер и `performance.timeOrigin` остались прежними: документ не перезагружался.
- В отдельном повторе смена ширины на 1440 снова сохранила черновик и маркер. После переключения флага эмулятора **mobile → desktop** маркер исчез, а `performance.timeOrigin` изменился с `1793604431538` на `1793604483544.1`: произошла перезагрузка документа.

Таким образом, прежнее наблюдение не подтверждает потерю черновика при обычной адаптивной перестройке. Воспроизведена потеря при перезагрузке эмулятором. Постоянное хранение черновика между перезагрузками в эти исправления не добавлялось. Отправка отзыва во время эксперимента не выполнялась.
